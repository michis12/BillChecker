# BillChecker

Ausgaben-App fürs Handy mit Rechnungsscan.

- Rechnung fotografieren → Betrag, Datum, Händler, Kategorie und Zahlungsmittel werden per Texterkennung (Tesseract.js, direkt im Browser) erkannt
- Übersicht nach Zahlungsmittel (Bar, Bankomatkarte, Kreditkarte, PayPal, Überweisung) und Kategorie
- Monatsbudget, Tagesverlauf, Suche
- CSV-Export (Monat / alles) und JSON-Backup
- Daten bleiben nur auf dem Gerät (IndexedDB), keine Datenbank
- Als App installierbar (PWA), funktioniert offline

Gehostet über GitHub Pages.
